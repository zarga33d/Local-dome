# Enhanced Honeypot - Advanced Security Tool
# ===========================================

## Overview
Enhanced Honeypot is a sophisticated security tool designed to detect, monitor, and protect against unauthorized access attempts and cyber attacks. It creates fake open ports to lure attackers and collect valuable threat intelligence.

## 🚀 Key Features



## use it from anywere
- "alias zhz='python home/path-to/zhoneypot_enhanced.py'




### 🔒 Hidden Files System
- Creates hidden database and log files (starting with dot)
- Files stored in root directory or current directory
- Only visible with `ls -la` or `dir /a` commands
- Cross-platform support (Windows, Linux, macOS)

### 🎯 Advanced Attack Detection
- Real-time attack pattern recognition
- SQL injection detection
- XSS attack detection
- Directory traversal detection
- Command injection detection
- Brute force attack detection

### 🛡️ Automatic IP Banning
- Automatic banning of attacking IPs via iptables
- Bans both INPUT and OUTPUT traffic
- Persistent ban restoration on restart
- Threat level calculation and scoring

### 📊 Comprehensive Logging
- Hidden SQLite database for attack records
- Individual JSON files for each attacker IP
- Session tracking and monitoring
- IP reputation scoring system

### 🌐 Service Simulation
- SSH server simulation (port 22)
- FTP server simulation (port 21)
- Web server simulation (ports 80, 443, 8080)
- RDP simulation (port 3389)
- Database simulation (ports 1433, 3306)
- Email server simulation (ports 25, 587, 465)
- And many more services...

## 📁 Hidden Files Structure

### Database Files
- `.honeypot_enhanced.db` - SQLite database with attack records
- `.honeypot_enhanced.log` - System logs and activities

### Attacker Files
- `.honeypot.js/` - Directory containing individual attacker files
- `{ip}.js` - JSON file for each attacking IP with detailed information

### File Locations
- **Windows**: `C:\`, `D:\`, `E:\` or current directory
- **Linux/macOS**: `/`, `~` (home directory), `/home/` or current directory

- iptables functionality simulated

## 🔍 Troubleshooting

### Common Issues
1. **Permission Denied**: Run as administrator/sudo
2. **Port Already in Use**: Change ports or stop conflicting services
3. **Database Locked**: Wait for operations to complete
4. **Hidden Files Not Found**: Check with `ls -la` or `dir /a`

### Debug Mode
- Enable verbose logging
- Check console output for errors
- Verify file permissions
- Test network connectivity
